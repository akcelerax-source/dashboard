Generated by `bench/final/final_analysis.py` (NFEI via `bench/final/nfei-score.mjs` → `src/data/nfei.js` v2.1). Config `NODEX-ARCH-2026.09-r6-bigmap`, held-out seeds **3, 4** (never used in development), scenarios S01 normal, S03 congestion, S06 comm delay, S07 comm loss, S08 robot failure, S09 deadlock, S13 combined, fleets 3/10/50/100, run rule: no time cap, run ends when all tasks complete or after 300 sim-s with no task completed (NO_PROGRESS, still scored), fault window 90 s. Sections 5 and 6 (before/after, ablation) were NOT run at the user's request and are empty.

Data files (all in `bench/results/final/`): `A_src_all.jsonl` (src, 3 systems), `B_before.jsonl` (src with NODEX_ABLATE=all = pre-optimization behaviour, all 3 systems), `C_ws1|ws2|ws3.jsonl` (ablations on src; ablation "all" = ACE rows of B_before), `D_acetests.jsonl` (ACE tests), `nfei_scores.json`.

Run counts: {'A': 168, 'B': 0, 'C_all': 0, 'C_ws1': 0, 'C_ws2': 0, 'C_ws3': 0, 'D': 24}.

Throughput = tasks completed × 3600 / T_obs (T_obs = makespan if all tasks completed, else sim time when the run ended). Win/loss rule (same as `BASELINE_SUMMARY.md`): more tasks completed wins, then shorter completion time (1 % band), else tie. Geo-mean ratios: exp(mean log ratio) over paired runs, 95 % CI = t-interval on the paired log ratios.
